⚠ Mid-tone (400) colours are decorative only
pos-400, cau-400, neg-400 do not achieve 4.5:1 contrast on their 50-stop backgrounds. They must not be used as text colour.

For text on tinted backgrounds: always use the 600-stop.
pos-600 (#1F6132) on pos-50 = 6.81:1 ✓ · cau-600 (#845A0C) on cau-50 = 5.67:1 ✓ · neg-600 (#8C2E1E) on neg-50 = 7.48:1 ✓

White text on sentiment mid-tones also fails (pos-400: 3.50:1, cau-400: 2.63:1, neg-400: 4.19:1). The wax seal face SVGs use white eyes/mouths on sentiment circles — these are graphic/decorative elements exempt under WCAG 1.1.1, but every sentiment SVG must have aria-label for screen readers.

400-stop valid uses: decorative dots, border accents, icon fills — never standalone text.

Minimum sizes & WCAG text spacing
Minimum rendered size: 11px. Never render text below 11px in any component. IBM Plex Mono at 9–10px (swatch stop labels, token pills) is decorative supplementary text — it always accompanies a visible colour swatch and never carries meaning alone. It is exempt under WCAG 1.1.1 but must not be relied upon for communication.

Large text threshold (lower contrast requirement of 3:1 applies):
≥ 18px normal weight = large text  ·  ≥ 14px bold weight = large text
Below these sizes: 4.5:1 required always.

WCAG 1.4.12 — Text spacing compliance:
line-height ≥ 1.5× font-size ✓ (body set to 1.65)
paragraph spacing ≥ 2× font-size — add margin-bottom: 1em to all <p>
letter-spacing ≥ 0.12× font-size — body text: letter-spacing: 0.012em
word-spacing ≥ 0.16× font-size — browser default sufficient, no override needed
03 — Motion
Animation system
Every animation rule is derived from Emil Kowalski's principles (Linear, Vercel). Springs for physics interactions. Custom cubic-bezier curves always — never browser defaults.
The 7 rules — Emil Kowalski
1. Scale buttons on press — scale(0.97) on :active. Instant feedback.
2. Never animate from scale(0). Start at scale(0.95) minimum. Elements don't appear from nothing.
3. Subsequent tooltips have no delay and no animation. Once one is open, the next opens instantly.
4. ease-out for enter/exit. ease-in-out for on-screen movement. Custom curves — never browser defaults.
5. Origin-aware animations. Popovers scale from their trigger, never from transform-origin: center.
6. Stay under 300ms. Faster = more responsive. Remove animations seen hundreds of times a day.
7. Blur on crossfade. filter:blur(2px) bridges two states and hides the visual seam.

Reduced motion — mandatory, not optional
prefers-reduced-motion: reduce affects approximately 35% of users over 40. Vestibular disorders make parallax and scaling animations physically disorienting. This is not an edge case.

When useReducedMotion() returns true:
All springs → duration: 0 (instant position change, no motion)
Layout animations → instant
Envelope idle bob → animation-play-state: paused
Number count-up → show final value immediately, skip animation
Map flyTo → instant setView() instead
Tooltip entrance → opacity only, 150ms
Modal entrance → opacity only, 150ms

Never suppress all feedback — only motion. Opacity transitions at 150ms remain active — they don't cause vestibular discomfort and still communicate state changes.

Implementation:
import { useReducedMotion } from 'framer-motion'
const reduce = useReducedMotion()
transition={reduce ? {"{duration:0}"} : springPreset}

CSS:
@media (prefers-reduced-motion: reduce) {"{"}
  .envelope-bob {"{"} animation-play-state: paused {"}"}
  .dot-pulse {"{"} animation-play-state: paused {"}"}
{"}"}
Performance — transform + opacity only
Every animation uses only transform and opacity. These trigger the composite rendering step only. Animating height, width, margin, or padding triggers layout + paint + composite. Apply will-change: transform to each .envelope marker to promote it to its own compositor layer — critical when 50+ envelopes are on screen simultaneously.

WCAG 2.4.11 — Focus appearance (AA in WCAG 2.2)
The focus indicator must enclose the component and have an area at least equal to a 2px perimeter around the component. A 3px ring on any component greatly exceeds this minimum. Never remove focus rings — only restyle them. The double-ring pattern (2px white gap + 2px coloured ring) ensures visibility on both light and dark backgrounds without relying on colour alone.
